# 构图与秩序

用于新构图、信息密度调整、画幅适配和系列设计。把瑞士的信息结构与日式的空间、文字和情绪表达放在同一个版面中处理，不要求用户先选择流派。

## 从阅读任务建立网格

先找主信息、内容分组、图像角色和观看距离，再确定可用版面。网格是内容之间的关系，不是需要画出来的背景。

- 文案较少时，一条主要对齐轴或一组明确的边缘关系可能已经足够。
- 多组信息先判断读者会连续读完还是来回查找，再选择栏、行或跨栏关系；有关联的组靠近，不同组之间保留明显间隔。手机长正文常适合纵向分组，多栏只有在目标显示宽度下仍可连续阅读时才成立。
- 多栏正文先保证可读行长；文字基线、段落起点和图片边缘共同建立秩序，不只对齐外框。
- 大标题和主图可以跨栏或偏离常规位置，但要与其他元素保留可辨认的关系。
- 固定栏数、黄金比例、三分法和固定留白百分比都不是通用正确答案。

先看黑白的视觉重量：主次如果只能靠颜色辨认，通常需要继续调整尺度、间距或位置。再加入颜色与图像，检查原有层级是否仍成立。

## 五个共同作用的要素

| 要素 | 决策问题 | 具体处理 |
|---|---|---|
| 版型 | 内容应当怎样被读到？ | 先组织分组和顺序，再决定对齐、轴向、跨栏与偏移。 |
| 字体 | 哪段话需要被看见，哪段需要被读完？ | 用角色分配字号、字重、字体和密度；标题可按主题做倾斜或比例处理，正文保证连续阅读，处理强度形成主次。 |
| 色彩 | 颜色承担什么任务？ | 区分背景、正文和强调用途；克制意味着减少无作用的颜色，不等于只能低饱和。 |
| 留白 | 哪些信息应聚合，哪里需要停顿？ | 同时考虑页边、组间、段间、行间与字内空间；大空白不能补救局部拥挤。 |
| 配图 | 图像是否提供了文字之外的必要表达？ | 主题照片、证据图和情绪图分别判断。不能因音乐会就擅加某类乐器演奏者；抽象节奏足以表达时不增加具体演出暗示。密集说明中的图标若只是重复标题含义，应把空间让给正文。 |

不要为“日式”自动加入红圆、印章、纸纹、竖排或日文字样，也不要为“瑞士”自动加入红黑配色、超大数字和可见网格。它们只有承担内容作用时才适合。

## 八种构成手法如何选择

| 手法 | 适合的任务 | 实施与失败信号 |
|---|---|---|
| 重复 | 系列、目录、同类信息 | 重复同一角色的边距、字号或形态；若所有项都争抢注意力，应恢复主次。 |
| 近似 | 同一主题的不同内容 | 保持共同骨架，只让与内容有关的变量变化；变化太多会失去关联。 |
| 渐变 | 顺序、递进、强弱变化 | 让尺度、疏密或明度随语义变化；没有顺序含义时不为了效果强加渐变。 |
| 放射 | 汇聚、扩散、中心事件 | 建立一个明确焦点；正文尽量放在稳定阅读区，避免所有字都旋转。 |
| 轴向 | 文字多、需稳定关系 | 选择主轴并建立次级锚点；过多互不相干的轴会让版面散开。 |
| 密集 | 多信息、局部强调 | 让密集区与疏朗区形成节奏；信息完整和阅读尺寸不能被密度牺牲。 |
| 对比 | 明确焦点或差异 | 选择最有效的尺度、重量、方向或空间对比；不同时把所有变量推到极端。 |
| 节奏 | 多组信息、连续阅读 | 用重复、停顿和变化组织进程；机械等距不一定符合内容关系。 |

从任务选一个主导结构，只有必要时才增加辅助手法，不凑齐八种。

## 非对称的平衡

几何居中与视觉居中不同。粗重文字、深色块、人物脸部和高对比图像可能比面积更大的浅色区域更重。

- 用共同左边缘、图片边缘、水平线或文字轴固定信息，即使画面两侧并不等大。
- 通过空白、尺度和位置形成平衡，不用镜像装饰机械配平。
- 标题略出网格可以制造张力；地址、时间、正文等需要连续阅读的信息应有稳定位置。
- 放大看字形与裁切，缩小看重心与阅读顺序。只有一个尺度成立时继续调整。

## 从具体内容选择结构

这些是决策示例，不是限定题材或预设模板；不要把示例颜色带到其他任务。

| 内容与阅读任务 | 结构选择及理由 | 需要纠正的信号 |
|---|---|---|
| 器物展：一个主题、少量活动信息，有明确的器物主体 | 图像承担材质与情绪，标题和活动信息共享轴线；主图偏置也可以保持秩序。 | 留白很好看，但时间地点被挤到看不清。 |
| 音乐会：六项短文案，没有给定演出者或乐器 | 用标题尺度、位置、重复节奏建立表现力；需要额外字形处理时按文字参考比较原形与候选，日期地点形成稳定信息组，不凭空补演出者或乐器。 | 图像替用户指定了音乐类型，或标题虽能读清，字形处理却使结构笨重、长横抢眼、主次混乱。 |
| 手机活动指南：多段正文、限制条件和时间表必须读完 | 先排正文与时间表，再压缩页头；按章节纵向阅读或选能保持字高的分栏，分组靠间距和文字角色建立。 | 大标题、重复图标挤占正文，两栏只能放大后阅读；不能靠整体放大导出像素解决。 |
| 品牌文字展：明确限定高饱和颜色、禁止摄影 | 用指定颜色的面积与明暗对比组织文字，选择小字可读的前景背景组合；文字和色块足以形成主题。 | 自动退回米白植物风，或为了配色让日期落在低对比区域。 |

## 内容变长与画幅改变

内容变长时重新估计正文需要的空间：先调整分组、栏宽、换行，收回不承担信息的图片和过大的页头，再微调字号、行距和字距；不能用挤压字形或无限缩小正文解决超载。仍容纳不下时，明确提出拆页或删改需求，未经允许不执行内容删减。

从竖版到横版，重设阅读路线、图像裁切和信息组位置；不要只把原稿缩小后加宽空白。系列作品共享字体角色、边距逻辑、间距层级和图像处理方式，但允许每张内容决定自己的焦点。
