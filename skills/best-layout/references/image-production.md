# 图片制作与检查

输出格式、正式文案与成功交付规则见 [技能入口](../SKILL.md)。画面分为素材与正式文字：素材负责主题或情绪，文字用实际字库排印。

## 制作路径

- 纯文字、几何、数值表格：直接用 [真实字体排字](local-typesetting.md) 合成 PNG，无需先生成底图。
- 摄影、插画、材质：使用宿主内置图像生成／编辑工具制作无字素材。提示只描述主体、构图、光线、配色、文字所需空间；明确不生成字、数字、标志或标注。查看结果，确认没有店招、伪文字等，再作为局部图片或背景导入。
- 已有图片：先查看，区分需要编辑的区域与必须保留的内容。优先复用已有无字底图／分层文字；只有成品位图时，使用内置图像编辑能力去除待替换文字，检查主体与保留区，再叠加真实排字。不要让模型重画排好的正式文字。

使用工具当前公开接口。以 Codex `image_gen` 为例：新图不传编辑目标；本地编辑先查看，再传路径字段；会话中无路径的目标才使用最近图片引用，不混用两种机制。默认非透明，用户要求透明时明确设置并核对。返回像素不一定等于提示中的数字；最终画幅由合成画布确定，图片通过等比例 contain／cover 放置，实际检查裁切。

图像工具不可用但作品只需文字与几何时可继续；需要的新素材确实无法取得时，说明具体缺口。不自动安装依赖或调用另外的付费服务。

## 文案与设计分离

从用户原文形成唯一文案清单；允许创作的部分先定稿。排字配置的 `copy` 存放全部正式文字，每个 ID 对应一个文字块；字体、尺寸、坐标等仅在配置字段内，不进入可见文字。配置供代理内部执行，普通用户无需填写或阅读。

文案中的空格、标点、简繁、日期、数值与单位保持不变。多个块重复同一文字必须来自用户要求的次数；不要把自己的方案名称、字体名、图像提示或编号填进 `copy`。清单与执行配置都不是最终交付。

生成素材时不要顺便生成正式文案。排字后发现错字，应修改文案或排字配置重新合成；发现图像问题，则修改素材后复用同一文案配置。不能把整张已排字图片再次交给模型重画，以免准确文字重新变形。

## 检查与修正

程序检查缺字、清单遗漏／重复、实际文字越界与重叠，不自动判断审美、对比度或图片中是否含多余文字。输出 PNG 仍须实际查看：

1. 逐项核对正式文案和画面内全部可见文字，包括图片素材自带的字。
2. 检查实际字库、字重及设计变换后的笔画、字腔、间距和中英数字关系；标题倾斜或拉长时，按 [文字排版](typography.md) 比较原形与候选，有意变形且能辨认仍不足以判定效果更好。码位覆盖不代替齊伋體等特殊字形的视觉核对。
3. 在原尺寸与指定观看宽度完整读正文、日期和地点。阅读吃力时重排、扩大文字区域或调整构图，不自动缩字、删字或只增加导出像素。
4. 全幅检查主次、重心、图文关系、裁切和不变区域。配图不新增用户未提供的具体人物、商品或事件暗示。
5. 定量图形对照数据检查比例与标签；几何元素不能冒充精确图表。检查实际像素、PNG 格式和透明需求。

长标题或横竖画幅改变时重设文字区域与素材位置；程序的换行不代替设计决定。已保留的排字配置适合重用文案，不能直接等比缩小整个竖版来交横版。

缺字和溢出应修正后再生成；没有可行修正或原文无法核准时不交付错误稿。普通制图只保留必要源配置／素材和最终 PNG，不额外制作验收文档。项目开发测试可记录其验证范围。

只展示经过检查的最终图片。若宿主图像工具原生显示中间素材，不声称 Skill 能隐藏它；最终消息仍只含图片，不附内部参数、字体清单或解释。
