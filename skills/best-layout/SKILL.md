# best-layout

从最重要的信息建立版面，让内容、文字与图像共同形成视觉。默认采用日式编辑设计的细腻表达与瑞士设计的结构方法；明确的品牌、参考、受众和用户选择优先。

以下图片交付约定用于制图请求。用户只要求诊断、方案、提示词或审阅本 Skill 时，交付所要求的内容，不额外生图。

## 制图交付约定

- 正式文字默认用随技能附带的真实字体排印，输出 PNG；需要摄影、插画等素材时使用宿主的内置图像能力制作无字素材，再合成成图。不制作或交付 SVG、HTML 预览页。
- 默认完成一版；只有用户要求多个方案、系列或多张图片时才扩展数量。
- 成功交付只展示成图，不附分析、提示词、参数、路径清单、方案名称、总结或邀约。工具已经原生展示成图时不重复展示；本地图片使用绝对路径的图片嵌入，替代文字保持简短。
- 保留作品正式文案。画面不混入布局说明、字体名称、色值、尺寸标注、网格参考线、提示词、制作注释、方案编号或状态标签。
- 此约定禁止的是未经要求的额外文字，不是删掉正文。用户提供的“设计说明”“01”等如果本身就是作品正式内容，必须保留。
- 生成失败、缺少关键原文或正式文案无法核准时，不用说明文字、提示词或错误图片冒充完成；只报告具体阻塞和最小解决动作。用户明确要求解释时可以解释。

## 从内容到成图

### 先确定阅读任务

从当前上下文提取用途、受众、观看场景、画幅、素材、主信息及交付数量。区分导出像素与图片实际显示大小；手机图文需要一个具体显示宽度来检查。只询问会实质改变内容或结果且无法自行确定的缺口；常规细节直接处理，不增加固定审阅轮次。

建立内部文案清单，逐项区分：

- **准确内容**：用户给定的标题、正文、名称、日期、数字、单位、引文及其必要关系。
- **可创作文案**：用户明确允许起草或改写的部分；先在内部形成最终文案，写入文案清单与排字配置。
- **设计指令**：字体气质、布局、颜色、图像角色、留白和限制。它们不属于画面文字。

不要把用户解释任务的整段话自动排进图片。不要补写未经要求的英文、日文、口号、署名或装饰文字。用户只给了标题时，图像可以丰富，信息不能编造。

### 再建立视觉关系

明确观众先看什么、再看什么、哪些信息需要一起读。少量文案可由标题或主图承担视觉；较长正文先安排在目标显示尺寸下可读的行长、分组与空间，再分配标题和图片。按这些内容关系建立网格、对齐轴、文字角色、颜色与留白。

设计新构图或重排画幅时读 [构图与秩序](references/composition.md)。其中的五大要素与八种构成手法是选择工具，不是每张图必须逐项使用的清单。含中文的制图读取 [文字排版](references/typography.md)，短标题同样需要字形与排印检查。

不把无衬线、非对称、低饱和、竖排、大标题或大留白固化为统一外观。文字承担主视觉时，先选合适字库，用字号、位置和间距建立表达；确需改变字形时自主选择倾斜或比例处理，按文字参考与原形比较后决定保留、减弱或撤回，不需要用户逐项指定。能辨认、无越界只证明部分质量，不能据此认定变形更好看；正式内容完整，不能用变形、缩小正文或删字掩盖信息超载。

### 制作与修正

按 [图片制作与检查](references/image-production.md) 选择素材与排字方式。含正式文案时读取 [真实字体排字](references/local-typesetting.md)，用附带的字体、文案清单和排字程序输出 PNG。纯文字与几何构成可直接完成；需要图像时先生成无字素材。字体、字号、间距和坐标通过实际排字执行，不再依靠生图提示词模仿。

修改既有图片时先看原图，明确编辑目标、允许变化与必须保留的内容。有分层源文件时修改原文字层；只有位图时，用图像编辑工具处理需要变化的素材或去除旧字，再排新文字。保留区域须复核，不能直接把新字压在旧字上。参考图与编辑目标分别标记。实际输出后检查图片，再做有针对性的修正。

## 完成前检查

- 正式文案逐项一致：无错字、漏字、无意重复、额外文字；标点、数字、日期和单位正确。
- 主信息突出，辅助信息有可追踪的阅读顺序；相同角色的字形、字重与间距关系一致。字词能辨认不等于排印质量已通过。
- 实际观看尺寸下文字可读，重要内容无裁切、遮挡、背景干扰或缺字。
- 图像、留白和色彩服务内容；检查配图是否暗示了未经提供的具体人物、产品、演出类型或事件。几何对齐与视觉重量协调，必要的不对称有秩序。
- 如含定量图形，数值、单位、比例、轴和图例关系真实一致；装饰性形状不冒充数据编码。
- 横竖画幅或内容量改变后已重新组织版面；系列图片保持共同的文字与间距关系。
- 检查通过后，按上方约定只展示图片；没有实际检查的部分不得称为通过。

## 资料与边界

[来源索引](references/sources.md) 记录日本与瑞士书籍、中文和日文排版资料，以及实际查阅范围。这里的执行方法是原创归纳；不复制书页或整张作品，不把书籍目录当作全文阅读，不宣称设计史只有单一路径。

技能自带字体和相对路径脚本；不依赖相邻项目、个人字体目录或额外模型 API。排字需要 Python、Playwright 和可用的 Chromium，见真实字体排字参考。先检查已有运行环境，不自动安装。纯文字图无需生图工具；需要的运行能力缺失时说明具体缺口，不把生成式仿字或其他格式冒充准确字体成图。
